几何体检视器 · 绘画参考   （GeometryViewer.exe，v1.8.3）
==========================================

用途
  绘画用的标准几何体检视器：屏幕上一次只放一个几何体，用类似建模软件的
  方式转视角、看结构，帮助判断透视与比例。六个模型共用同一套取景尺度，
  切换时相机不动，所以可以直接比较它们的大小关系。

运行
  双击 GeometryViewer.exe 即可（若遇到蓝色「Windows 已保护你的电脑」，
  见下面一节；或者直接双击同目录的 启动.cmd）。
  单文件，无需安装 .NET 或任何运行库。
  首次启动时 Windows 会把内置的运行库解包到 %TEMP%\.net 缓存目录，
  之后启动就很快（一般 1~2 秒）。

  关于蓝色的「Windows 已保护你的电脑」（SmartScreen）
  这是 Windows 对「从网上下载、又没有购买代码签名证书的 exe」的通用提示，
  判定发生在程序启动之前，程序内部无法关闭它，也不是程序本身有问题。
  三种消除办法，从省事到彻底：

    ① 双击本目录里的「启动.cmd」。
       它会把 exe 上的「来自网络」标记（Zone.Identifier）清掉再启动。
       标记一清，以后直接双击 GeometryViewer.exe 也不会再弹。

    ② 右键 GeometryViewer.exe →「属性」→ 常规页最下面勾选「解除锁定」→ 确定。
       效果与 ① 相同（① 就是替你做这一步）。只需做一次。

    ③ 彻底根治只有买代码签名证书（EV 证书能立刻消除提示，OV 证书要累积下载
       信誉）。个人自用工具没必要为此花钱，用 ① 或 ② 即可。
       自签名证书对别的电脑无效，还会因为「不受信任的根」出现更醒目的警告，
       所以没有采用。

  注意：如果弹窗里只有「不运行」、点「更多信息」也没有「仍要运行」，
  说明系统开着「Smart App Control」（Win11 的新机制，会直接拦未签名程序）。
  这种情况只能用 启动.cmd 之外的改法：设置 → 隐私和安全性 → Windows 安全中心
  → 应用和浏览器控制 → 基于信誉的保护 → 关闭对应用和文件的检查。
  关掉会降低系统防护，请自行权衡（Smart App Control 一旦关闭，
  要重装系统才会回到评估状态）。

尺寸规则（全部以正方体棱长 a 为基准）
  正方体：棱长 a
  球体：  直径 √2·a  ≈ 1.414a   （同棱长正方体的外接球——画石膏几何体时的标准配比）
  圆柱体：底面直径 a，高 2a
  长方体：底面 a×a 的正方形，高 2a
  圆锥体：底面直径 a，高 2a
  阿萨罗头：整体高 1.86a（含颈部与底座），与其它模型同位落地；照着 Asaro《Planes of
           the Head》石膏像的照片量过比例后逐块建面（平顶颅骨、整块额面、眉弓台阶、
           杏仁形眼窝、楔形鼻、口块、宽下颌、带耳轮与耳甲的耳朵、方形底座），
           用来练头部结构与明暗分组。
  六个模型都放在原点、底面落在 y=0 地面；一次只显示一个。

操作
  左键拖拽      旋转视角（环绕）
  中键拖拽      平移视角：几何体原地不动，只有摄像机在它当前所在的那个平面里滑动
  右键拖拽      平移（同上，给没有中键的鼠标用）
  滚轮          缩放
  双击视口      回到初始视角
  「适配窗口」  自动缩放使几何体入画
  「重置视角」  恢复到初始相机姿态（X 0°、Y 0°、Z 0°，即正前方略高）

右侧边栏
  1) 俯视图：显示当前几何体的占位、摄像机位置（青色点）、视线中心（橙色点）
     与水平视野射线；左上角显示当前视距。
  2) 摄像机角度：X 俯仰 / Y 方位 / Z 滚转，三个轴的设置完全一样。
     每一行有三种改法：
       · 点数值框（整行都能点）打开下拉，里面是 15° 整数序列，
         X、Z 为 -90°~90°，Y 为 -180°~180°；
       · 点左侧「−」或右侧「+」按 15° 一档步进（这一排一定会响应点击）；
       · 鼠标停在该行上用滚轮微调。
     开下拉后也可以直接用键盘 ↑ ↓ 选择、Enter 确认、Esc 取消（或 Alt+↓ 打开）。
     数值是相对初始视角（X 0°、Y 0°、Z 0°）的偏移量，选中后摄像机会移动到对应角度。
     自由拖拽产生非整数角度时，下拉显示「自定义」。
     改完角度会自动重新取景，几何体始终完整落在视窗内；仰角压得很低时
     相机会跑到地面以下，这时地面会自动隐藏，只看几何体本身。
  4) 透视（「摄像机角度」栏里焦距下面的一排小按钮）
     每个模式都预设好灭点的个数与方位关系（"先定灭点、再定相机"），程序据此
     把相机朝向钉死，所以透视结构不会被转乱；但焦距仍可自由改——
     改焦距＝灭点沿画面中心整体向外推远或向内拉近，个数与方位关系不变。
     -- 一点：1 个灭点（纵深方向，画面正中）。方位 0°、俯仰 0°、滚转 0° 全部锁定，
        只剩焦距可调。
     -- 两点：2 个灭点（视平线左右）。锁定在方位 45°、俯仰 0°、滚转 0°；焦距可调，
        焦距越短灭点越靠里、越有冲击力。
     -- 三点：3 个灭点（上面两个 + 正上方）。锁定在方位 45°、俯仰 −27°、滚转 0°。
     -- 鱼眼：等距鱼眼镜头，三轴与焦距都能调（可到 180°），靠边的棱会明显外弯。
     切到一点／两点／三点时会自动打开「透视线」，红／绿／蓝射线直指灭点，便于对照；
     切回「自由」后所有参量恢复可调。
     旋转：两点／三点模式下方有一个「旋转」按钮，打开后可以绕竖直轴（两点）或水平轴
  5) 当前模型：球体 / 圆柱体 / 正方体 / 长方体 / 圆锥体 / 阿萨罗头 六选一（默认正方体）。
  6) 透视线：开关「显示消失点连线」，把当前几何体的棱线沿退行方向延长到
      这个角度的消失点，用来看消失点在哪里、棱线该往哪收。红／绿／蓝分别
      对应 X／Y／Z 三轴；消失点落在画面内时会画一个小圈＋十字。
      被几何体挡住的那一段会变淡，穿过地面时不会被地面遮住。
      默认关闭。
  7) 尺寸关系：上面那张基准表。

结构线的含义
  绘画意义上的结构线：竖轴（虚线）、1/4·1/2·3/4 高度的横截面、
  截面上的 X/Z 直径、圆柱的母线、圆锥的斜母线、正方体/长方体的顶面对角线、
  球体的赤道与朝向镜头的经线。被遮挡的部分会变淡，
  透明（仅轮廓线）模式下以青色细线全部画出。

红色中线（加粗）
  在结构线之上，另外用较粗的红线画出「中线」，也就是把形体对半分开的
  那几根线，落笔起形时最先用得上：
    正方体 / 长方体：每个面上的十字中线（竖中线 + 腰线），顶面也有十字。
    圆柱体：上下底面的两条直径（呈 X），以及那四个端点上的四条竖母线。
    圆锥体：底面的两条直径（呈 X），以及从四个端点收向锥顶的四条斜线。
    球体：竖直极轴 + 中间水平面的两条直径（十字）+ 过两极的两条经线大圆。
          极轴和十字是从球心穿过去的构造线，不会被球面挡住，所以中心一定连通。
  被几何体挡住的部分同样会变淡。
  开关：跟「显示结构线」一起开关，不单独设开关。

透视线的含义
  一点透视时（X 0°、Y 0°）只有 Z 轴有消失点，X／Y 轴的线保持平行；
  两点透视时 X 与 Z 各有消失点；仰角较大时 Y 轴的消失点会到画面下方。
  球体只有竖直中轴一条引导线（球面上没有直线棱）；圆柱只有竖直线族；
  圆锥的侧面上没有竖直线，只有中轴。

附：命令行（一般用不到，做图或批处理时方便）
  GeometryViewer.exe --shot out.png --w 1600 --h 1000 --ss 2 --mode translucent --solid sphere
     直接渲染一张 PNG 到文件，不开窗口。
  --mode   opaque | translucent | outline
  --solid  sphere | cylinder | cube | cuboid | cone | asaro   选择显示的几何体
  --show   00010   旧写法：五位开关，顺序 球 圆柱 正方体 长方体 圆锥
  --el --az --roll  视角偏移（与界面上的三个下拉同义，单位度）
  --mm 24           焦距（35mm 等效），与界面上的「焦距」行同义
--lens 2p         透视类型：free / 1p / 2p / 3p / fish（与界面「透视」按钮同义）
  --fov 60          直接给垂直视野角（度），与 --mm 同时给时以 --fov 为准
  --struct 0        关闭结构线
  --persp  1        打开透视线（消失点连线），0 为关闭
  --ui out.png      把整个界面截成 PNG（调试用）
