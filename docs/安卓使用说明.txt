几何体检视器 · 安卓版   （GeometryViewer-Android.apk，v1.5）
============================================================

一、这是什么
------------
和电脑版是同一套几何与渲染代码（同一个软件光线投射渲染器），只是界面按手机/平板
重新做了一版：竖屏时画面在上、控制面板在下，横屏时面板移到右侧；所有尺寸用 dp
计算，从 5 寸手机到 13 寸平板都不会挤在一起或糊掉。

一次只显示一个模型（球体 / 圆柱体 / 正方体 / 长方体 / 圆锥体 / 阿萨罗头），六个模型共用同一
个「基准 a＝正方体棱长」的尺度，切换时取景不变，所以可以直接比大小：
  球     直径 √2a
  圆柱   底圆直径 a、高 2a
  长方体 底面 a×a、高 2a
  圆锥   底圆直径 a、高 2a
  正方体 棱长 a
全部底面落在地面上，彼此同位。

二、安装
--------
1) 把这个 apk 传到手机上（数据线 / 微信文件传输 / 网盘都行）。
2) 点开它。第一次装「非应用商店」的包，系统会拦一下：
   · 小米/红米：设置 → 应用设置 → 应用管理 → 右上角…→ 特殊权限 → 安装未知应用 → 允许。
   · 华为/荣耀、OPPO/vivo、三星类似，都会提示「允许来自此来源的应用」，点允许即可。
   · 如果提示「应用未经过安全检测」，那是手机自带的应用商店保护，选「继续安装」。
3) 装好后桌面会出现「几何体检视器」图标，直接打开。

签名信息：包名 com.georef.geometryviewer，版本 1.9（versionCode 10），
最低支持 Android 7.0（API 24），APK 用 v2+v3 签名，35.1 MB。
（这一版特意关掉了「裁剪 + AOT 预编译 + 新的封送方法」，宁可包大一点也要先保证能打开。）

三、手势
--------
· 单指拖动        —— 绕着物体旋转（横向改方位角，纵向改俯仰角）
· 双指捏合/张开   —— 缩放（拉近拉远）
· 双指拖动        —— 平移画面：物体原地不动，只有摄像机在它当前所在的那个平面里
                     滑动（和 Blender / SketchUp 的「平移视图」一样，指哪滑哪）
· 松手后会自动出一张精细图；拖动过程中显示的是低分辨率预览，所以手感是顺的

三之二、画面上的两个小按钮（电脑版没有）
----------------------------------------
· 角落的「横屏」    —— 点一下整块界面强制横过来（像看视频那样铺满整屏、隐藏状态栏），
                      再点一下回到竖屏 / 跟随系统。注意它用的是「传感器横屏」，会压过
                      系统设置里的「自动旋转」开关，这样才不会被系统限制住；按钮底色变青
                      就是强制横屏开着。
· 参数栏上边缘的三角形 —— 参数面板和画面之间那条窄条上有个 ▼，点一下把面板收起来
                      （画面占满），收起来后变成 ▲，点一下再展开。竖屏收起后面板只留
                      一条 26dp 的窄条，横屏收起后只剩 18dp 宽的一条。

四、右侧（竖屏是下方）面板
--------------------------
1) 模型        —— 点一下弹出六个模型（含「阿萨罗头」，按 Asaro 面块划分的低多边形头像），选哪个就显示哪个。
2) 模样        —— 不透明 / 半透明 / 仅轮廓线（线稿）。
3) 结构线      —— 青色细结构线：竖轴、1/4、1/2、3/4 高度截面、各截面直径、母线等。
                  同时会画红色加粗中线：立方体每个面的十字、圆柱上下底十字＋四条竖
                  母线、圆锥底面十字＋四条斜母线、球体竖轴＋赤道十字＋两条经线。
                  被物体挡住的线自动变淡（球心十字和竖轴是穿体构造线，不会被挡）。
4) 透视线      —— 把棱线延长到当前角度的消失点，红/绿/蓝＝X/Y/Z 轴；消失点在画面
                  内时会标出小圈。
5) 摄像机角度  —— X 俯仰 / Y 方位 / Z 滚转，各 15° 一档：
                  · 点「−」「+」按 15° 步进；
                  · 点中间的数值，直接弹出预设角度列表（X/Z 为 −90°…90°，
                    Y 为 −180°…180°）；
                  · 角度是相对初始视角（X 0°、Y 0°、Z 0°）的偏移；
                  · 改完角度会自动重新取景，保证物体还在画面里。
6) 焦距        —— 14 / 18 / 24 / 28 / 35 / 50 / 85 / 135 / 200 mm（35mm 等效），
                  右边同时显示垂直视野角。短焦（14mm≈81°）近大远小夸张，长焦
                  （135mm≈10°）接近轴测。换焦距会自动补偿距离，物体大小基本不变，
                  变的是透视强度。点数值可直接挑档。
7) 适配窗口 / 重置视角 —— 前者重新取景（保留当前角度和焦距），后者回到初始
                  视角（X/Y/Z 全 0、50mm）。
8) 画面左上角的小图 —— 俯视图：灰白轮廓是当前几何体，青点＝摄像机，橙点＝视线
                  中心，青色扇形＝水平视野，虚线＝视线，「视距 x.x a」是相机距离。

五、画面左上角的状态行
----------------------
「不透明 · 结构线 开」这样一行，显示当前模样与开关状态。

六、已知限制
------------
· 手机上是实时软件渲染，第一次进入或刚改完参数时会有 0.2~1 秒的「正在渲染…」；
  拖动时用低分辨率预览，松手才出精细图。
· 极低仰角（相机跑到地面以下）时地面会自动隐藏，只留物体和背景，这是正常的。
· 没有做「导出图片」按钮；需要存图的话用手机截屏。

七、打不开（闪退）时怎么办
--------------------------
这一版加了自检：万一启动时出错，屏幕上会直接显示一段「启动失败（请把这段文字截图
发给开发者）」+ 错误详情，不会再只是黑一下就没了。

如果仍然一打开就消失，按这个顺序试：
1) **看屏幕底部有没有一闪而过的黑色小气泡（Toast）**，文字会是这些之一：
      0 App / 1 OnCreate / 2 window / 3 viewport / 4 panel / 5 UI ready
   它出现在哪一条、下一条没出现，就说明崩在那一步之间 —— **把最后看到的那个词告我**，
   这一条信息比日志还准（Toast 由系统绘制，程序死了它还在）；
2) 再装一次工作区里的 MinProbe.apk（最小探针，包名不同，可与主程序共存）：
   它用**和主程序完全相同的工程设置、清单写法、签名**，但只显示一行绿字
   「MIN PROBE OK」。
   · 它能打开 → 说明工程设置没问题、是我们的界面代码；请接着做第 3 步；
   · 它也闪退 → 问题在工程/打包设置，跟界面代码无关，我会照这个方向查；
3) 再装 RenderProbe.apk（渲染探针，同样包名不同）：
   它只跑渲染核心、没有面板，屏上会一行行显示
   「1 scene / 2 fit ok / 3 render ok xx ms / 4 bitmap ok」，
   **把那个画面截图发过来**；
4) 如果上面都正常、只有主程序闪退，那就在文件管理里找日志：
     内部存储 / Android / media / com.georef.geometryviewer / startup.log
   （旧版写的 Android / data / … / files / 从 Android 11 起文件管理器一般看不到，
   这一版已改到 Android / media / 下，能直接找到，连电脑 MTP 也能拷）。

八、文件位置
------------
· GeometryViewer-Android.apk      —— 安装包（就在工作区根目录）
· MinProbe.apk                    —— 最小探针（排查闪退用，只显示「MIN PROBE OK」）
· RenderProbe.apk                 —— 渲染探针（排查闪退用，只跑渲染核心）
· GeometryViewer-Android\         —— 安卓工程源码
    GeoViewerAndroid.csproj         工程文件（复用 ..\GeometryViewer-Project\src\Core 与 \Render）
    MainActivity.cs                 界面、面板、横屏按钮、收面板三角形与手势的接线
    ViewportView.cs                 旧的自定义视口（已不参与编译，留作参考）
    AndroidManifest.xml             清单
    Resources\drawable-nodpi\icon.png  图标
    编译.cmd                        一键重新编译（纯 ASCII，双击即可）
    README.md                       工程说明与重新编译的方法
· probe-render\                   —— RenderProbe 的工程源码（同样复用 Core 与 Render）
